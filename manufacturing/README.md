# Manufacturing outputs

This directory is reserved for exports generated from the reviewed KiCad source:
- Gerbers
- drill files
- BOM
- pick-and-place / centroid
- assembly drawing
- schematic and PCB PDFs
- ERC/DRC reports

No fabrication exports are included yet because no final KiCad schematic/PCB source has been frozen and verified. Add generated outputs only after ERC/DRC review and independent Gerber inspection.
